# 🛡️ ArabShield AI Pro
### نظام ذكي لاكتشاف الاحتيال الإلكتروني في المحادثات العربية

## 1. نبذة عن المشروع

ArabShield AI Pro هو نظام ذكي يهدف إلى اكتشاف مؤشرات الاحتيال الإلكتروني في المحادثات باللغة العربية باستخدام تقنيات الذكاء الاصطناعي والتعلم العميق.

يعتمد النظام على نموذج LSTM لتحليل النصوص وتصنيف المحادثات إلى:
- محادثات يُحتمل أنها احتيالية (Scam).
- محادثات سليمة (Not Scam).

كما يستخدم تقنية LIME لتفسير نتائج النموذج وإظهار الكلمات التي ساهمت في قرار التصنيف.

## 2. أهداف المشروع

- اكتشاف مؤشرات الاحتيال الإلكتروني في المحادثات العربية.
- الاستفادة من تقنيات التعلم العميق في تحليل النصوص.
- تقديم تفسير مفهوم لنتائج النموذج.
- توفير واجهة استخدام عربية سهلة.
- حفظ نتائج التحليل والرجوع إليها لاحقًا.

## 3. التقنيات المستخدمة

| التقنية | الاستخدام |
|---|---|
| Python | لغة البرمجة |
| TensorFlow / Keras | بناء وتشغيل نموذج LSTM |
| LSTM | تصنيف المحادثات |
| LIME | تفسير نتائج النموذج |
| Streamlit | بناء واجهة المستخدم |
| SQLite | تخزين سجل التحليلات |
| NumPy | العمليات العددية |
| Pandas | معالجة البيانات |

## 5. آلية عمل النظام

يمر تحليل المحادثة بالمراحل التالية:

1. إدخال نص المحادثة.
2. معالجة النص وتطبيعه.
3. تحويل النص إلى تسلسل رقمي باستخدام Tokenizer.
4. توحيد طول التسلسل إلى 150.
5. تمرير البيانات إلى نموذج LSTM.
6. استخراج احتمالية الاحتيال.
7. تحديد التصنيف النهائي.
8. تفسير الكلمات المؤثرة باستخدام LIME.
9. حفظ نتيجة التحليل في قاعدة بيانات SQLite.

## 6. مكونات النظام

### نموذج LSTM
يستخدم لتحليل المحادثات العربية والتنبؤ باحتمالية وجود مؤشرات احتيال.

### تقنية LIME
تساعد في تفسير التنبؤ من خلال عرض الكلمات التي ساهمت في اتجاه التصنيف.

### واجهة Streamlit
توفر واجهة عربية للتفاعل مع النظام وإدخال المحادثات وعرض النتائج.

### قاعدة بيانات SQLite
تُستخدم لحفظ المحادثات التي تم تحليلها ونتائجها ونسب الاحتمالات وتاريخ التحليل.

## 7. تثبيت المشروع وتشغيله

### المتطلبات
- Python 3.11
- ملفات النموذج وTokenizer.
- المكتبات الموضحة في requirements.txt.

### إنشاء البيئة الافتراضية

```bash
python -m venv .venv
```

### تفعيل البيئة في Windows

```bash
.venv\Scripts\activate
```

### تثبيت المكتبات

```bash
pip install -r requirements.txt
```

يجب التأكد من توافق إصدار TensorFlow مع نظام التشغيل وإصدار Python.

### تشغيل النظام

```bash
streamlit run app.py
```
